## Books

- Martin Kleppmann, *Designing Data-Intensive Applications*, O'Reilly Media, chapters on stream processing, replication, and consistency.
- Justin Sheffield, *Learning Apache Flink*, O'Reilly Media, foundations of stateful stream processing.
- Thomas Hunter, *Redis in Action*, Manning Publications, Redis data structures and distributed deployment patterns.
- Ian Millington, *Game Physics Engine Development*, CRC Press, deterministic simulation concepts relevant to game-server state.
- Gernot Lankes, *Game Physics Engine Development, 2nd Edition*, CRC Press, simulation and real-time system design.

## Websites

- [Apache Kafka](https://kafka.apache.org/) — durable event logs, consumer groups, delivery semantics, and stream-processing documentation.
- [Apache Flink](https://flink.apache.org/) — stateful stream processing, windows, watermarks, and checkpointing documentation.
- [Redis sorted sets](https://redis.io/docs/latest/data-types/sorted-sets/) — sorted-set commands and ranking primitives.
- [Redis Streams](https://redis.io/docs/latest/data-types/streams/) — Redis event-stream data type and consumer groups.
- [Microsoft Orleans](https://learn.microsoft.com/en-us/dotnet/orleans/) — distributed virtual actors and state synchronization patterns.
- [CloudEvents](https://cloudevents.io/) — event metadata interoperability specification.
- [OpenTelemetry](https://opentelemetry.io/) — traces, metrics, and logs for event and game-system observability.
