## Websites

- [FATF standards and guidance](https://www.fatf-gafi.org/en/publications/Fatfrecommendations.html) — AML/CFT standards, risk-based approaches, and recommendations.
- [FinCEN Financial Trend Analysis](https://www.fincen.gov/resources/statistics-and-intelligence/financial-trend-analysis) — suspicious activity typologies and reporting context.
- [FinCEN SAR filing guidance](https://www.fincen.gov/resources/statutes-regulations/guidance) — US suspicious activity reporting requirements and forms.
- [OFAC sanctions list search](https://sanctionssearch.ofac.treas.gov/) — official sanctions data search and list resources.
- [United Nations Security Council Consolidated List](https://main.un.org/securitycouncil/en/content/un-sc-consolidated-list) — UN sanctions list and amendments.
- [W3C Verifiable Credentials Data Model](https://www.w3.org/TR/vc-data-model/) — credential, issuer, holder, verifier, and proof data model.
- [W3C Decentralized Identifiers](https://www.w3.org/TR/did-core/) — DID syntax, DID documents, resolution, and method requirements.
- [FIDO Alliance WebAuthn specification](https://www.w3.org/TR/webauthn-2/) — WebAuthn protocol, authenticator data, and client authentication ceremonies.
- [OpenID Connect Core](https://openid.net/specs/openid-connect-core-1_0.html) — OIDC ID tokens, authorization requests, and user claims.
- [OAuth 2.0 Security Best Current Practice](https://datatracker.ietf.org/doc/html/draft-ietf-oauth-security-topics) — authorization-server and client security guidance.
- [SAML 2.0 Technical Overview](https://docs.oasis-open.org/security/saml/v2.0/saml-core-2.0-os.pdf) — SAML assertions, protocols, bindings, and profiles.
- [ISO/IEC 30107-3 presentation attack detection](https://www.iso.org/standard/79520.html) — biometric presentation-attack detection terminology and testing.
- [NIST Digital Identity Guidelines](https://pages.nist.gov/800-63-3/) — identity proofing, authentication, and federation assurance guidance.
- [EASL Verify](https://github.com/eu-digital-identity-wallet/eudi-doc-architecture-and-reference-framework) — European digital identity wallet reference resources.
- [NIST Privacy Framework](https://www.nist.gov/privacy-framework) — risk-based privacy controls for identity and biometric processing.
