Start with these data structures before reading the algorithm chapters. You do not need to master
every implementation first; you need to recognize the operations each structure makes cheap.

## Data Structures

1. **Arrays** — contiguous storage with constant-time indexed access.
2. **Linked lists** — nodes connected by references, useful when insertion and removal happen at known nodes.
3. **Stacks, queues, and deques** — restricted access patterns for LIFO, FIFO, and double-ended work.
4. **Hash tables and sets** — key-based lookup and membership testing with expected constant-time operations.
5. **Trees and heaps** — hierarchical data, ordered search, and priority-based retrieval.
6. **Graphs** — vertices and edges for relationships, dependencies, and routes.
7. **Union-Find** — a compact structure for tracking connected components as edges are added.

## Core skills

- Read and write loops, conditionals, functions, and simple classes.
- Know references, mutation, recursion, and the difference between a value and a reference to a value.
- Estimate time and space growth using input size \(n\).
- Trace an algorithm by hand on a small input before optimizing it.
