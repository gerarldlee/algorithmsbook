Start with these data structures before reading the algorithm chapters. You do not need to master
every implementation first; you need to recognize the operations each structure makes cheap.

## Data Structures

1. **[Arrays](../01-algorithms/01-linear-data-structures/01-dynamic-arrays.md)** — contiguous storage with constant-time indexed access.
2. **[Linked lists](../01-algorithms/01-linear-data-structures/02-linked-lists.md)** — nodes connected by references, useful when insertion and removal happen at known nodes.
3. **[Stacks, queues, and deques](../01-algorithms/01-linear-data-structures/03-stacks-queues-deques.md)** — restricted access patterns for LIFO, FIFO, and double-ended work.
4. **[Hash tables and sets](../01-algorithms/01-linear-data-structures/04-hash-tables.md)** — key-based lookup and membership testing with expected constant-time operations.
5. **[Trees](../01-algorithms/02-search-trees/01-binary-search-trees.md) and [heaps](../01-algorithms/02-search-trees/02-heaps-priority-queues.md)** — hierarchical data, ordered search, and priority-based retrieval.
6. **[Graphs](../01-algorithms/04-graphs/01-graph-representations.md)** — vertices and edges for relationships, dependencies, and routes.
7. **[Union-Find](../01-algorithms/02-search-trees/05-union-find.md)** — a compact structure for tracking connected components as edges are added.

## Core skills

- Read and write loops, conditionals, functions, and simple classes.
- Know references, mutation, recursion, and the difference between a value and a reference to a value.
- Estimate time and space growth using input size \(n\).
- Trace an algorithm by hand on a small input before optimizing it.
