Sources for [Distributed Version Control Mechanics](01-distributed-version-control.md) and the chapter's [branching and review workflow](01-distributed-version-control.md#how-it-works). Return to the [Chapter 12B overview](_index.md) for chapter scope.

## Books

- [Pro Git, Second Edition](https://git-scm.com/book/en/v2) by Scott Chacon and Ben Straub — covers Git's object model, branching, remotes, and distributed workflows from the command line to hosting platforms.
- [Git: The Missing Guide](https://www.oreilly.com/library/view/git-the-missing/9781449344567/) by Adam Stubblefield — introduces repository structure, branching, remotes, and collaboration for readers new to distributed development.
- [Git for Teams](https://gitforteams.com/) by Matthew O'Keefe, Catherine Krasyk, and Microsoft GitHub team — explains branching models, pull requests, review policy, and team-wide Git conventions.

## Websites

- [Git Reference](https://git-scm.com/docs) — official command and conceptual documentation for Git's object database, refs, merge, rebase, and recovery operations.
- [Git Internals - Git Objects](https://git-scm.com/book/en/v2/Git-Internals-Git-Objects) — explains blobs, trees, commits, and content-addressed object identity.
- [Git Rebase Documentation](https://git-scm.com/docs/git-rebase) — defines commit replay, interactive editing, merge backends, and recovery behavior.
- [GitHub Docs: About Pull Requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests) — describes the branch, review, checks, and merge workflow implemented by GitHub.
- [Google Engineering Practices: The Code Review Developer Guide](https://google.github.io/eng-practices/review/) — provides review guidance for change size, comments, approvals, and reviewer responsibilities.
- [GitLab Docs: Merge Requests](https://docs.gitlab.com/user/project/merge_requests/) — documents another implementation of proposal, discussion, approval, pipeline, and merge gates.
