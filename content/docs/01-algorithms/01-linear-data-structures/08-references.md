The sources below support the topics in Chapter 1. The chapter pages explain the mechanisms; this page collects the shared books and websites used to verify their definitions, operations, and costs.

## Books

| Source | Topics |
| --- | --- |
| [Introduction to Algorithms](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/) | Arrays, linked lists, stacks, queues, hashing, probabilistic structures, and asymptotic analysis |
| [Algorithms, 4th Edition](https://algs4.cs.princeton.edu/home/) | Data-structure implementations, correctness, and complexity analysis |
| [Grokking Algorithms](https://www.manning.com/books/grokking-algorithms) | Intuitive introductions to data structures and probabilistic counting |
| [The Algorithm Design Manual](https://www.algorist.com/) | Design tradeoffs, data-structure selection, and practical implementation guidance |
