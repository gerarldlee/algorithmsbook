The sources below support the topics in Chapter 4. The chapter pages explain graph representations and algorithm invariants; this page collects the shared books and websites used to verify them.

## Books

| Source | Topics |
| --- | --- |
| [Introduction to Algorithms](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/) | Graph representations, BFS, DFS, topological sorting, SCCs, spanning trees, shortest paths, and network flow |
| [Algorithms, 4th Edition](https://algs4.cs.princeton.edu/home/) | Graph data structures, priority queues, pathfinding, matching, and complexity analysis |
| [The Algorithm Design Manual](https://www.algorist.com/) | Graph modeling, algorithm selection, and practical implementation tradeoffs |
| [Grokking Algorithms](https://www.manning.com/books/grokking-algorithms) | Intuitive introductions to graph search, greedy algorithms, and heuristic methods |
