The sources below support the topics in Chapter 2. The chapter pages explain tree operations, invariants, and tradeoffs; this page collects the shared books and websites used to verify them.

## Books

| Source | Topics |
| --- | --- |
| [Introduction to Algorithms](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/) | Balanced search trees, heaps, B-trees, range queries, union-find, tries, suffix structures, and parsing |
| [Algorithms, 4th Edition](https://algs4.cs.princeton.edu/home/) | Priority queues, interval indexes, tries, suffix arrays, spatial indexes, and complexity analysis |
| [The Algorithm Design Manual](https://www.algorist.com/) | Tree selection, storage-engine indexes, parser design, and practical tradeoffs |
| [Grokking Algorithms](https://www.manning.com/books/grokking-algorithms) | Intuitive introductions to trees, hashing, and recursive data structures |
