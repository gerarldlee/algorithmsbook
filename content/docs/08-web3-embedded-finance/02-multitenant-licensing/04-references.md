- Betsy Beyer, Jennifer Petoff, and Niall Richard Murphy, eds., [*Site Reliability Engineering*](https://www.oreilly.com/library/view/site-reliability-engineering/9781491929124/). O'Reilly Media, 2016.

## Websites

- [AWS SaaS Lens](https://docs.aws.amazon.com/wellarchitected/latest/saas-lens/saas-lens.html) — reliability, security, performance, and operational guidance for multi-tenant SaaS.
- [Microsoft Azure Architecture Center: Multitenant solution architecture](https://learn.microsoft.com/azure/architecture/guide/multitenant/) — isolation, deployment, and tenant-aware design patterns.
- [NIST SP 800-207: Zero Trust Architecture](https://csrc.nist.gov/pubs/sp/800/207/final) — continuous authorization and least-privilege principles relevant to tenant-scoped access.
- [IETF RFC 7519: JSON Web Token](https://www.rfc-editor.org/rfc/rfc7519) — registered claims and JWT processing requirements.
- [IETF RFC 8725: JSON Web Token Best Current Practices](https://www.rfc-editor.org/rfc/rfc8725) — security requirements for JWT implementation and claim validation.
- [Stripe Billing](https://docs.stripe.com/billing) — subscription, usage billing, invoicing, and collection behavior from a production payment provider.
- [Open Policy Agent documentation](https://www.openpolicyagent.org/docs) — policy evaluation, decision logs, and policy-as-code foundations.
